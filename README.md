# Island World

Мод для Minecraft **26.3** на Fabric: генерирует мир-остров посреди океана, ограничивает его невидимой границей
и прячет всё, что за границей, в «Чёрную комнату».

Остров — примерно 2000 блоков в поперечнике, климат распределён с севера на юг, за береговой линией только океан.
За пределами радиуса 2000 игрока убивает «неизвестная сущность» и выбрасывает на случайный край острова.

> **Состояние на 27.10.2026** — ветка `main`, коммит `1aef9c7` («Polishing»), версия мода **1.0.1**.
> Всё описанное ниже реализовано в коде и собирается CI; игровая проверка генерации и баланса в репозитории не
> зафиксирована.
> Подробное техзадание и обоснование решений — в [`docs/PLAN.md`](docs/PLAN.md). Этот файл описывает **что есть
сейчас**, план — **что задумано**.

## Требования

| Компонент              | Версия                                |
|------------------------|---------------------------------------|
| Minecraft              | `26.3` (в `fabric.mod.json`: `~26.3`) |
| Fabric Loader          | `0.19.5` и новее                      |
| Fabric API             | `0.164.0+26.3`                        |
| Fabric Language Kotlin | `1.14.2+kotlin.2.4.21`                |
| Java                   | `25` (и для запуска, и для сборки)    |

Мод написан на Kotlin (`fabric-language-kotlin` — обязательная зависимость), Java используется только для миксинов.
Среда выполнения — `*` (клиент и сервер), но вся игровая логика серверная.

## Сборка и установка

```bash
./gradlew build
```

Готовый jar — в `build/libs/`. Для запуска нужен JDK 25: Gradle 9.7.1, Kotlin 2.4.21, Loom `1.18-SNAPSHOT`,
`options.release = 25` / `JvmTarget.JVM_25`.

Локальный запуск клиента и сервера — стандартными задачами Loom (`runClient`, `runServer`).

Установка: положить jar и Fabric API в `mods/`, выбрать при создании мира пресет **«Остров в океане»**
(`generator.islandworld.island`) — он добавлен в тег `minecraft:normal`, поэтому виден в обычном списке пресетов.

## Что уже работает

Точка входа — `IslandWorldMod` (`islandworld`, `com.thelameres.islandworld`). Подсистемы подключаются списком,
порядок важен: сначала общий `Lifecycle`, потом генерация мира, метки, игровые подсистемы. Каждая реализует
`Registrable.register()` и сама подписывается на нужные события; состояние по игрокам и по сессии сервера
собирается и очищается в одном месте (`core/Lifecycle.kt`, интерфейсы `PlayerScoped` / `SessionScoped`).

### Генерация мира

- **Пресет `islandworld:island`** (`data/islandworld/worldgen/world_preset/island.json`) — обычный overworld,
  но со своими `noise_settings` (`islandworld:island`); Незер и Энд ванильные.
- **Маска острова** — кастомная density function `islandworld:island_mask`: радиус **1000**, `edge_softness` **250**,
  амплитуда шума **200**, шум `minecraft:offset` с `xz_scale 0.005`. Радиус искажается шумом, поэтому берег неровный.
- **Континенты** строятся через `lerp` по маске: внутри `−0.15`, снаружи `−1.0` (глубокий океан). `final_density`
  остался ванильным — океан обеспечивается значением `continents`, а не умножением плотности (умножение давало пустоту
  под водой).
- **Температура с севера на юг** — `islandworld:north_south_temperature`: линейный градиент по Z от `cold_z −1000`
  (север, −1.0) до `hot_z +1000` (юг, +1.0), поверх него подмешан ванильный шум `minecraft:temperature` с весом `0.45`,
  чтобы не было ровных полос.
- **Сжатие климата** — `islandworld:scaled_climate` (scale 4) для `continents`, `erosion`, `ridges`; `vegetation`
  остался ванильным. Климатические поля «сжимаются», чтобы на острове поместилось больше биомов.
- **Переопределённые ванильные функции** — `offset`, `factor`, `jaggedness` для `minecraft:overworld` ссылаются
  на маску острова, так что рельеф и биомы используют одну геометрию. Правка глобальная: ванильный пресет
  при установленном моде тоже получит эти значения.
- **Океанские биомы** — переопределены все девять (`ocean`, `deep_ocean`, `cold_ocean`, `deep_cold_ocean`,
  `frozen_ocean`, `deep_frozen_ocean`, `lukewarm_ocean`, `deep_lukewarm_ocean`, `warm_ocean`): убраны карверы (никаких
  пещер под водой), дно сделано толще.
- **Стронгхолды** — кастомное размещение `islandworld:ocean_concentric_rings`: 128 колец, `distance 32`, `spread 3`,
  предпочтительные биомы `#minecraft:is_ocean`, отсекаются чанки ближе `island_radius 800` и дальше `max_radius 1900`
  от центра. То есть крепости есть только в океане вокруг острова, но не на самом острове.

### Стартовая точка

Первый вход игрока (`FirstJoinSpawn`): от точки `(-930, 600)` (юго-запад) ищется ближайшая суша — кольцами с шагом
4 блока и 6° до радиуса 400, — затем место у берега: под ногами земля/трава/песок, точка и место над головой свободны,
дерева сверху нет, океан в квадрате 8 блоков вокруг. Поиск берега идёт уже от найденной суши, в радиусе 200.
Найденная точка кешируется на сессию сервера (`SpawnUtil`) и записывается в `server.respawnData`. Список уже
зашедших игроков — `islandworld_joined.txt` в корне папки мира (по одному UUID на строку, `util/FirstJoinStore.kt`).

Если место не нашлось, игрок **не** помечается зашедшим — попытка повторится при следующем входе.

### Граница острова

`BoundaryManager` раз в `check_interval_ticks` (по умолчанию 10 тиков) считает евклидово расстояние от центра:

1. **1800 / 1900 / 1950** — три предупреждения строго по порядку (даже если игрок перескочил сразу несколько порогов).
   На каждой стадии накладываются эффекты из конфига (`Hallucination`: darkness / nausea / slowness, 300 тиков).
2. **2000** — смерть через собственный тип урона `islandworld:unknown` (`bypasses_invulnerability` в теге, так что
   бессмертие не спасает) после задержки `kill_delay_ticks` (160 тиков) за границей.
3. Возврат в безопасную зону (`warn1_radius − reset_radius_margin`) сбрасывает счётчики.

Творческий режим и наблюдатель урона не получают. Звук смерти — два события: жертва слышит `unknown_death`
(без позиции, `MASTER`), остальные — `unknown_death_distant` в точке смерти (`attenuation_distance 4000`).

После смерти от границы (`EdgeRespawn`) игрок попадает на **случайный край острова**: до 24 попыток, случайный луч
от центра, поиск берега в пределах `max_radius 1799`, проверка безопасной точки по поверхности. Иначе — обычный респавн.

### Чёрная комната и порталы

- Измерение `islandworld:black_room` со своим генератором: **9×9 чанков** (144×144 блока), барьерный пол на `Y = 63`,
  рамка портала Незера 4×5 из обсидиана с порталом 2×3 в центре `(8, 64, 8)`. Чанки за пределами комнаты пустые.
- Тип измерения: без неба и солнечного света, с потолком, ambient light 0, чёрный туман от 10 до 96 блоков,
  кровати не работают, рейдов нет, спавн мобов запрещён и на уровне типа, и в биоме, и в генераторе.
- **Wrap-around** на границе: раз в 9 тиков сущности за пределами `[-64, 80)` переносятся на противоположную сторону,
  так что выйти из комнаты нельзя.
- **Защита**: запрещено ломать и ставить блоки, использовать блоки; мобы при загрузке удаляются;
  после смерти игрок возвращается в Overworld.
- **Маршрутизация порталов** (`PortalRouting` + `MixinNetherPortal`): вход в портал Незера, у которого эквивалент
  в Overworld (`x·8`, `z·8`) дальше 2000 блоков от центра, ведёт в Чёрную комнату. Выход из комнаты возвращает
  к тому самому порталу — позиция входа запоминается в `ReturnPortalStore`. Все остальные случаи — ванильное поведение.
  Миксин не принимает решений: он только спрашивает `PortalRouting` и подставляет результат.

### Компас, метки и LocatorBar

- **Waypoint-метки**: Shift + ПКМ компасом по табличке или флагу включает метку, повторный — снимает.
  Хранилище — `SavedData` уровня (`WaypointStore`, id `islandworld:waypoints`), ключ — `BlockPos`,
  поэтому метка не дублируется и живёт независимо от блочной сущности: чанк можно выгрузить, метка останется.
  В NBT блоков ничего не пишется. Имя берётся из первой непустой строки таблички или из имени флага,
  иначе — переводимая заглушка с координатами. Сообщения локализованы (`islandworld.waypoint.*`).
- **Синхронизация с чанками** — через миксины `MixinLevelChunkWaypoint` (появление/удаление блочной сущности)
  и `MixinBlockEntityWaypoint` (маркерный интерфейс `BlockWaypointTransmitter` для `SignBlockEntity` и
  `BannerBlockEntity`;
  висячие таблички покрыты наследованием). Вся логика — в Kotlin (`WaypointChunkHooks`).
- **LocatorBar** — используется ванильный, свой HUD и сетевой канал не нужны. `CompassLocator` каждый тик правит
  атрибуты: `waypoint_receive_range` обнуляется без компаса в руке, `waypoint_transmit_range` — если на голове
  `PLAYER_HEAD`.
  Кеш состояния по UUID сбрасывается на респавне (`AFTER_RESPAWN`), потому что новый `ServerPlayer` не наследует
  временные модификаторы атрибутов.
- **HUD координат** (`CompassCoordinatesHud`): если в руке компас, в левом верхнем углу выводится `x | y | z`.
  В ванильных измерениях — реальные координаты; в любых других (включая Чёрную комнату) — **случайные числа**,
  обновляемые каждые 5 тиков. Это задуманная галлюцинация, а не баг.

## Конфигурация

Файл `config/island_config.json` создаётся автоматически при первом запуске сервера (`BoundaryConfig.kt`,
Gson с pretty printing). При ошибке чтения используются значения по умолчанию — мир не ломается.

```json
{
  "boundary": {
    "center_x": 0.0,
    "center_z": 0.0,
    "warn1_radius": 1800.0,
    "warn2_radius": 1900.0,
    "warn3_radius": 1950.0,
    "kill_radius": 2000.0,
    "kill_delay_ticks": 160,
    "check_interval_ticks": 10,
    "reset_radius_margin": 100.0,
    "debug_messages": false
  },
  "respawn": {
    "max_radius": 1799.0,
    "attempts": 24,
    "coast_check_radius": 12
  },
  "hallucinations": {
    "stage1": {
      "effects": [
        "darkness:1",
        "nausea:1"
      ]
    },
    "stage2": {
      "effects": [
        "darkness:2",
        "nausea:2",
        "slowness:1"
      ]
    },
    "stage3": {
      "effects": [
        "darkness:2",
        "nausea:3",
        "slowness:2"
      ]
    }
  }
}
```

- Эффекты задаются строкой `"имя:уровень"`, уровень считается с 1; поддерживаются `darkness`, `nausea`, `slowness`,
  неизвестное имя пишется в лог и пропускается.
- `debug_messages` включает служебное сообщение о стадии границы над хотбаром.
- Радиусы границы и радиус поиска респавна независимы: респавн намеренно чуть ниже первого предупреждения,
  чтобы игрок не получал его сразу после смерти.

Геометрия острова (радиус, мягкость края, амплитуда шума) задаётся не здесь, а в датапаке:
`data/islandworld/worldgen/density_function/island_mask.json`.

## Чего ещё нет

- **Команд нет ни одной** — ни `/island biomes report`, ни `/island locate_portals`: в коде нет
  `CommandRegistrationCallback`.
- **Своего биом-сорса** — набор и расположение биомов определяет ванильный `multi_noise`, гарантий «все биомы есть» нет.
- **Запрета ручной постройки портала Энда** и связанной с ним логики.
- **Клиентской части галлюцинаций**: шейдеров, виньетки, тряски камеры, фейковых сущностей. `IslandWorldClient`
  содержит только HUD компаса и заглушку `ClientMixin.java` (пустой класс, в `client`-список миксинов не входит).
- **Сжатия `vegetation`** и тонкой настройки пляжей: попытка расширить полосу `coast` через «полку» на уровне −0.15
  ломала рельеф (океан пропадал, низины затапливались) и была откатана. Пляжи сейчас примерно 12–18 блоков.

## Известные особенности и ограничения

1. **Старые миры не обновляются.** Правки density functions и `noise_settings` не применяются к уже сгенерированным
   чанкам — нужен новый мир.
2. **Глобальное переопределение ванильных функций.** `offset`, `factor`, `jaggedness` для `minecraft:overworld`
   переопределены в датапаке мода, поэтому при установленном моде изменения получает и ванильный пресет.
3. **Числа подобраны расчётом и на глаз.** Генерацию и баланс границы нужно смотреть глазами в `runClient`;
   в репозитории нет ни одного прогона, который бы это подтверждал.
4. **`config/island_config.json` читается один раз при инициализации** — после правки нужен перезапуск сервера.
5. **Несоответствие лицензий.** `LICENSE` — CC0 1.0, а в `fabric.mod.json` указано `"license": "MIT"`. Нужно выбрать
   одно.
6. **Рассинхрон `modId` в сборке.** В `build.gradle.kts` блок `fabricApi.configureDataGeneration` объявляет
   `modId = "world-island-mod"`, тогда как реальный id мода — `islandworld`, и entrypoint генерации данных не заведён.
   На сборку не влияет, но блок мёртвый.
7. **CI на self-hosted раннере** с метками `[self-hosted, rpi]` — сборка не запустится на GitHub-hosted раннерах форка.
8. **Описание в `fabric.mod.json` устарело** («остров ~1500x1500 блоков»): маска задаёт радиус 1000, то есть
   около 2000 блоков в поперечнике. Актуальная геометрия — в `island_mask.json`, а не в описании мода.
