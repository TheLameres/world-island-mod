# Island World

Мод для Minecraft 26.3 / Fabric Loader 0.164.0+26.3. Добавляет пресет мира «Island World»: остров посреди океана,
температура с севера на юг, океанские биомы за пределами острова.

> Статус разработки. Легенда: ✅ сделано · 🟡 частично · ⬜ не начато · ❌ отличается от исходного плана.

### Дополнительно сделано (не было в плане)

- Переопределены девять океанских биомов (`minecraft:*_ocean`): без пещерных карверов, толще дно океана.
- Глубокий океан (`continents = −1`) снаружи острова, остров суша внутри.
- `offset`, `factor`, `jaggedness` переопределены в датапаке мода: рельеф и биомы используют одну маску острова.
- Пляж расширен (сейчас примерно 12–18 блоков). Попытка сделать пляж шире откатана: см. «Известные проблемы».

## Известные проблемы

1. **Пляжи тонкие.** Полоса `coast` (континентальность −0.19…−0.11) проходит за 11–18 блоков. Прямое расширение через
   «полку» на уровне −0.15 сломало рельеф (океан пропадал, низины затапливались) и откатано. Нужен другой подход,
   например отдельная функция для пляжа.
2. **Не проверено в игре.** Все числа подобраны расчётом по сплайнам ванили или на глаз. Генерацию нужно смотреть в
   `runClient`.
3. **Высокие берега** после правки `clamp(…, −0.30, 0.45)` могут остаться. Если так, уменьшить верхний предел.
4. **Старые миры.** Правки density functions не применяются к уже сгенерированным чанкам: нужен новый мир.
5. **Переопределение ванильных функций.** `offset`, `factor`, `jaggedness` переопределены для `minecraft:overworld`
   глобально, поэтому ванильный пресет тоже получит новые значения при установленном моде.
6. **Расхождение с `origin/main`.** В удалённой ветке есть коммиты «Add island generator», которых нет в локальной
   истории. Патч поверх `origin/main` делается отдельно.

## Отличия от исходного плана, которые стоит знать

- Радиус острова 1000, а не 750 (меняется в `island_mask.json`).
- Температура использует шум, а не только градиент.
- В плане `final_density` умножается на маску. В текущей версии это не сделано, океан обеспечивается через `continents`.
  Это безопаснее: умножение дало бы пустоту под водой.
- В плане в примерах используются старые API (`DensityFunction.compute(FunctionContext)`, конструктор
  `ResourceLocation`, `ClientboundAddEntityPacket` в старом виде). Перед реализацией их нужно сверить с 26.3 через
  `javap` или `genSources`.
- В плане в `SpawnUtil` условие `!level.getFluidState(candidate).isEmpty() == false` указано с ошибкой: двойное
  отрицание. Логика проверки воды должна быть переписана.
- Текст `generator.islandworld.island` в плане — «Остров в океане», в репозитории — «Островной мир» (`ru_ru.json`).
  Выберите один вариант.

## Сборка

Требования: JDK 25, Fabric Loom под 26.3.

```bash
./gradlew build
```

Артефакт — в `build/libs/`.
